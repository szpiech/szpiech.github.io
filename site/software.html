Software

Software developed in the lab is open source and available on GitHub. If you use one of these programs, please cite the papers listed with it.


selscan

Computes haplotype-based statistics for detecting recent positive selection (EHH, iHS, XP-EHH, nSL, XP-nSL, and iHH12). It runs on phased or unphased data and is available through Bioconda.

Papers: Szpiech and Hernandez (2014), Szpiech et al. (2021), Szpiech (2024), Rahman et al. (2025), Rahman et al. (2026)

lassip

Computes haplotype frequency spectrum statistics for detecting hard and soft selective sweeps, including saltiLASSI, LASSI, H12, H2/H1, G123, and G2/G1. It runs on phased or unphased data, with or without missing genotypes.

Papers: DeGiorgio and Szpiech (2022), Sequeira et al. (2026, preprint)

GARLIC

Calls runs of homozygosity (ROH) in genotype data and classifies them by length.

Papers: Szpiech et al. (2017), Blant et al. (2017)

ADZE

Uses rarefaction to estimate allelic richness and private allelic richness while correcting for differences in sample size among populations.

Papers: Szpiech et al. (2008), Szpiech (2026, preprint)

LODESTAR

Finds genomic regions where local patterns of relatedness depart from the genome-wide pattern or from sampling geography, using multidimensional scaling and Procrustes analysis. It is available through Bioconda.

Papers: Smith et al. (2025, preprint)

DSTAR

Computes D*, a rarefaction-based statistic for identifying local introgression in a three-population tree that does not require an outgroup. It is available through Bioconda.

Papers: Smith and Szpiech (2026)

EGGS

Modifies genotype data to resemble empirical data by removing phase, unpolarizing alleles, pseudohaploidizing samples, adding sequencing error, and introducing missing genotypes. It also converts EIGENSTRAT files to VCF. It is available through Bioconda.

Papers: Smith et al. (2026)

Utilities

asd

Computes pairwise allele sharing distances and genetic relationship matrices with multiple threads.

divstats

Computes diversity statistics in windows, including nucleotide diversity, the number of segregating sites, Tajima's D, Fay and Wu's H, and EHH.

predictGMAP

Interpolates genetic map positions for a set of query positions from a reference genetic map.

Rxy-kin

Computes the Rxy statistic for testing purging of deleterious alleles, with support for related samples.

blue_af

Computes best linear unbiased estimates (BLUE) of allele frequencies using a kinship matrix and writes them in GARLIC's .freq format.

ROHsims

Simulation code from Szpiech et al. (2019) AJHG.

More code is available on GitHub.
